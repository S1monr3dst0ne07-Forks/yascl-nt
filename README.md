
# YASCL (Yet Another Systems Compiler Language)

Yascl is a low-level, untyped, 64-bit programming language.
It is currently **working in progress** and hence subject to change.

Yascl's primary aim is to be simple,
both in its feature-set and compiler implementation.
Yascl is bootstrapped, ergo implemented in itself.
